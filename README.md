# Neon Racer 🏎️

A simple browser-based car racing game built with vanilla HTML, CSS and JavaScript.

## Play locally
1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Press **MULA BERMAIN** to start.

## Controls
- **Desktop:** Arrow Left / Arrow Right or A / D
- **Mobile:** Use the on-screen left and right buttons

## Features
- Dodge traffic and survive as long as possible
- Score and best-score tracking (saved in browser local storage)
- Increasing difficulty
- Keyboard and touch controls

No dependencies or build tools required.
